# Fallback contributions

This is a workspace for useful changes that can be reviewed independently when an
upstream contribution is blocked by permissions, duplication, missing maintainer
direction, unclear scope, or unavailable validation.

A fallback contribution must:

1. improve this project's ability to scout, analyze, plan, validate, or document;
2. have a narrow acceptance criterion;
3. include appropriate validation;
4. be recorded in the daily log with the upstream reason; and
5. avoid pretending that repository activity is an upstream contribution.

Do not copy upstream code here or use this directory as a holding area for
speculative patches.
