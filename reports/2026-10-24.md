## Problem evidence and expected impact
Issue #5149 reports that using the OpenCode Free provider dashboard Test button can cause 429 FreeUsageLimitError or 403 FreeTierError and interrupt subsequent client requests. In the current source, `src/app/api/models/test/ping.js` sends a synthetic 1024-token chat request, and the saved-connection probe in `src/app/api/providers/[id]/test/testUtils.js` uses the legacy `opencode/1.18.31` user agent. The current OpenCode executor separately documents v2 headers and upstream sensitivity. The safest narrow response is to disable dashboard-only probes for `opencode`, leaving ordinary client inference unchanged. This is a precaution based on issue evidence; no live upstream test was performed.
