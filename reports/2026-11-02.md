## Selected opportunity
**External repository:** [jackwener/OpenCLI](https://github.com/jackwener/OpenCLI). **Issue:** [#2755 — Legacy sitemap-author skill copy has invalid YAML after 1.8.6 install](https://github.com/jackwener/OpenCLI/issues/2755).

The reporter documented a real Pi diagnostic against `~/.agents/skills/opencli-sitemap-author/SKILL.md`. OpenCLI 1.8.6 shipped an unquoted colon in YAML `description`; a fix landed in 1.8.7, and the sitemap skills were removed in 2.0.0. Upgrading the npm package does not necessarily remove independently installed agent skills. The current [README](https://github.com/jackwener/OpenCLI/blob/main/README.md) advertises `npx skills add jackwener/opencli` for refreshing supported skills but lacked guidance for orphaned legacy copies.

**Impact:** Helps affected users restore skill loading without accidentally deleting other agent skills, misdiagnosing the current package, or reintroducing unsupported functionality. Documentation is a focused, reviewable solution to the reported migration gap. No speculative runtime behavior was changed.
