## Selected issue and evidence

Issue: https://github.com/jackwener/OpenCLI/issues/2697

The Reddit adapter (https://github.com/jackwener/OpenCLI/blob/main/clis/reddit/read.js) fetches the initial post/comments tree successfully, but its optional `/api/morechildren` request returns `kind: auth` on HTTP 401/403, which the Node adapter maps to `AuthRequiredError`, discarding the initial visible tree. The user can lose accessible evidence merely by requesting optional expansion.

The requested improvement is explicitly **not** an authentication bypass: preserve already accessible comments, indicate incomplete coverage, and keep initial-post access failures strict. This is a useful read-only reliability improvement for research and agent consumers.
