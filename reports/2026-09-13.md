## Implementation

Created branch `fix/validate-output-format` from current upstream main commit `8271afc67e8504bda94c147f446ee29775d08274`.

Changes:
1. Imported `ArgumentError` in `src/output.ts`.
2. Defined the documented public output-format set once inside the renderer.
3. Preserved existing internal aliases `markdown` and `yml`.
4. Rejected unsupported formats before any output is emitted with the message:
   `--format must be one of: table, plain, json, yaml, md, csv. Received: "<value>"`
5. Replaced the switch `default` with an explicit `case 'table'` so unsupported values cannot silently fall through.
6. Added a regression test in `src/output.test.ts` verifying `bogus` throws and emits no output.
