## Implementation

Commit: `fa6db1e297e53e1a9caeb75854e45e3b68cd9509`
Commit message: `fix(twitter): poll bookmark confirmation state`

Changed `clis/twitter/bookmark.js` so that after the bookmark click it polls the target article every 500ms for up to 10 attempts (5 seconds total) for the idempotent `removeBookmark` state. If confirmation still never appears, the existing uncertain-write path remains: the command raises `TimeoutError` and tells the user to check the tweet before retrying. The timeout metadata was updated from 1 to 5 seconds to match actual behavior.
