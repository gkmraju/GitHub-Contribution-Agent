# Getting help

For a reproducible defect in this repository, open a bug report using the issue
form and include the smallest safe reproduction. For a proposed capability, use
the feature request form and describe the user problem and alternatives.

Please remove credentials, private prompts, personal data, and sensitive logs
before posting. Use synthetic values in examples. A public issue is not a place
to disclose vulnerabilities; do not include exploit details or secrets in public
reports.

This project is early and has no response-time or support guarantee. The public
offline demo shows the current CLI boundary and does not imply that hosted or
autonomous execution is available.
